# WrenchAndWeb — Plumbing Demo Website

WrenchAndWeb's flagship demonstration website for independent plumbing businesses in Houston, Texas.

## Purpose

This project shows prospective clients what a modern, high-converting plumbing website can look like before they commit to a project. It is used in sales conversations to demonstrate:

- A clear, mobile-first layout built for customers searching on their phones
- Prominent tap-to-call and "Request a Quote" calls to action
- Service pages that explain common plumbing jobs in plain language
- Lead capture that can connect to a simple CRM and follow-up workflow
- Fast loading, accessible design and trustworthy presentation

## Demo content policy

This is a **demonstration project**, not a real business website.

- All company details are fictional and clearly labelled as a demo.
- Phone numbers use the (713) 555-01XX range reserved for fictional use.
- No real reviews, licences, awards or customer data are used or invented.
- Test form submissions must use test data only.
